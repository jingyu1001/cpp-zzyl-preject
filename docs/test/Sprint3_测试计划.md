1. **段 A（10 min，隐藏不占窗口）**：跑 `--selftest` 11 帧 + `--empty-data` + `--db` 覆盖；转 PNG 目检 09/10/11；静态核验 dev3 `s3_logs` / `s3_ui` / CSV / DB。

## 4. 风险与对策

| 风险 | 对策 |
|---|---|
| 多 agent 抢前台（Sprint2 已踩坑） | 严格 cpp-control 排队；测试前核实 0 实例；分段执行避免长时间占用 |
| 坐标/按钮自动定位失败 | 沿用 Sprint2 收尾方案：遮罩亮度判定 + 严格亮绿质心；必要时键盘 Tab/Enter |
| 默认库被污染 | 全部用 `--db` 临时库；默认库只做「首次建库/幂等」隐藏启动（可接受） |
| M4 表单字段多、坐标复杂 | 优先自测帧 10 确认布局，再按分区逐段操作；超时则拆第二轮窗口 |
| 证据不足导致误判 | 双证据法：截图 + 日志/DB 文件/重启；不确定项标「待补证」不猜 PASS |
| 删除/写库影响共享环境 | 使用隔离 DB 路径，测试结束不清理默认库 |
